2. shift：把「昨天」搬到今天這一列
c = aaa["Close"] t = pd.DataFrame({"Close": c, "prev": c.shift(1), # 昨天 "next": c.shift(-1)}) # 明天 t.head()
Close prev next Date 2026-03-02 100 NaN 102.0 2026-03-03 102 100.0 99.0 2026-03-04 99 102.0 105.0 2026-03-05 105 99.0 110.0 2026-03-06 110 105.0 108.0

日報酬率 = 今天 ÷ 昨天 − 1

r = c / c.shift(1) - 1 # 自己算 r = c.pct_change() # pandas 內建，結果相同
  • 第一天沒有昨天 → shift(1) 是 NaN → 第一天的報酬率也是 NaN。
  • 10 個價格只能算出 9 個報酬率——和單元 2 用 for 迴圈 range(1, len(p)) 的道理一樣。
  • shift(-1) 是把明天的價格搬過來。分析時用到它要非常小心：今天的你不可能知道明天的價格（單元 7 回測會再談）。

3. 累積報酬：要「連乘」，不能「加總」
r = aaa["Close"].pct_change() r.sum() # ❌ 直接加總 (1 + r).prod() - 1 # ✅ 期間總報酬 (1 + r).cumprod() - 1 # ✅ 每天的累積報酬 c = aaa["Close"] c.iloc[-1] / c.iloc[0] - 1 # ✅ 頭尾相除

標準化：把起點都變成 1（或 100）

norm = aaa["Close"] / aaa["Close"].iloc[0] # 1.0, 1.02, 0.99, 1.05, 1.1, ...

不同股價的股票（100 元 vs. 2000 元）放在同一張圖比較時，一定要先標準化。

為什麼不能加總？（單元 2 學過）

天報酬價值
0—100
1+10%110
2−10%99

加總：+10% − 10% = 0%；實際：−1%。

💡 prod() 是連乘、cumprod() 是「累積連乘」，就是單元 2 的 for 迴圈 value = value * (1 + r) 的一行版本。

第一天的報酬是 NaN，所以累積值也從 NaN 開始；最後一天 1.2 代表賺 20%。

7. 時間序列的資料整理：順序最重要

證交所下載的資料常常是「新到舊」

dates = ["2024-01-05", "2024-01-04", "2024-01-03"] x = pd.Series([110, 105, 100], index=pd.to_datetime(dates)) x.pct_change() # ❌ 方向相反 # [nan, -0.0455, -0.0476] 明明在漲，卻算出下跌 x.sort_index().pct_change() # ✅ 先排序 # [nan, 0.05, 0.0476]
x.index.is_monotonic_increasing # False → 沒有由舊到新

2330_dirty.csv 的整理步驟（單元 4 的技巧＋時間序列）

raw = pd.read_csv(DATA_URL + "2330_dirty.csv", thousands=",") raw = raw.rename(columns={"日期": "Date", "收盤價": "Close", "成交股數": "Volume"}) raw["Date"] = pd.to_datetime(raw["Date"]) raw = raw.drop_duplicates() raw = raw.set_index("Date").sort_index() # 重點 raw["Close"] = pd.to_numeric(raw["Close"], errors="coerce")

📌 時間序列整理的檢查清單：日期有轉換、由舊到新、沒有重複日期，再算報酬率。

⚠️ 本單元的「AI 常犯錯誤」專欄

報酬率算錯，後面的風險、回測就全錯了：

① 用 Close 算報酬
忽略股利，報酬被低估；遇到沒調整的分割，還會出現假暴跌。
👉 算報酬一律用 Adj Close
② 日期沒有由舊到新
新到舊的資料直接 pct_change()，漲跌方向全部相反。
👉 檢查：index.is_monotonic_increasing
③ 報酬率直接加總
r.sum() 不是總報酬，期間越長誤差越大。
👉 用 (1 + r).prod() - 1 或頭尾價格相除
④ 用到「明天」的資料
shift(-1) 把未來的價格放到今天，分析結果會好到不真實。
👉 看到 shift(-1) 先停下來想一想

步驟 1：給 AI 的指令（範例）

「我有 adj_close_wide.csv（Date 加上 2330、2317、2454、0050 四欄還原收盤價）。請用 pandas 計算每檔股票 2025 年全年的報酬率，並畫出 2025 年的標準化走勢圖（起點 = 100，圖上文字用英文）。」

步驟 2：先想清楚定義

「2025 年全年報酬」= 2025 年最後一個交易日 ÷ 2024 年最後一個交易日 − 1。用 2025 年第一天當起點，會少算 1 月 2 日當天的報酬。

步驟 3：驗收清單

  • ☐ 日期有轉換，而且由舊到新
  • ☐ 起點、終點的日期正確
  • ☐ 2025-08-01 的缺值有處理
  • ☐ 用的是還原價（這個檔案本身就是）
  • ☐ 用連乘或頭尾相除，不是加總日報酬
參考答案（2025 年全年報酬）
2330 46.5%、2317 29.8%、2454 5.2%、0050 36.9%
（2024/12/31 → 2025/12/31，還原價）
