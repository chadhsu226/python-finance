本單元的財金問題
「『股價站上 20 日均線就買、跌破就賣』——這個常見的策略，真的比一直抱著好嗎？為什麼網路上、AI 給你的回測績效常常好到不真實？」

回測（backtest）是什麼？

用過去的資料模擬：「如果當時照這個規則交易，結果會怎樣？」

回測是最容易「騙自己」的分析。程式完全不會報錯，但只要一個小細節錯了，績效就可能放大十倍。

1. 均線策略：從訊號到部位
ma = c.rolling(20).mean() # 20 日均線 sig = (c > ma).astype(int) # 站上均線 = 1 pos = sig.shift(1) # ★ 明天才持有 r = c.pct_change() # 每日報酬 strat = pos * r # 策略報酬
變數意義
sig今天收盤後看到的訊號（1 = 想持有）
pos今天實際有沒有持股（1 = 有）
strat有持股才賺賠，沒持股報酬為 0

💡 astype(int)：把 True/False 轉成 1/0。

⭐ 為什麼要 shift(1)？訊號要等到今天收盤才算得出來，收盤後就不能再用今天的價格買進。最快只能從明天開始持有，所以只能賺到明天的報酬。

3. 回測最致命的錯誤：look-ahead bias（偷看未來）
wrong = sig * r # ❌ 忘了 shift right = sig.shift(1) * r # ✅
AAA 前 6 天總報酬
買進持有8.0%
均線策略（正確）2.9%
均線策略（忘了 shift）9.1% ← 打敗買進持有？

忘了 shift 時，3/5 那天「看到收盤價 105 站上均線」，卻同時賺到 3/5 當天從 99 漲到 105 的 +6.06%——等於用收盤價決定要不要在前一天買進。

為什麼這麼危險？

  • 程式完全不會報錯，只是績效「好得驚人」。
  • 均線策略的訊號，很多時候就是因為當天大漲才出現。偷看當天報酬，等於事後挑出漲最多的日子。
  • 真實資料中差距可以到十倍以上（下一頁之後的台積電例子）。

⭐ 判斷原則：用來做決定的資料，必須在做決定的那一刻就已經知道。單元 5 預告過的 shift(-1)，是同一類錯誤。

🔍 預測輸出 2：抓出 look-ahead bias

延續上一題：p（6 天）、sig = [0, 0, 0, 1, 1, 1]、r = p.pct_change()

Q1
print(round((1 + sig * r).prod() - 1, 4))
0.0909
1.0606 × 1.0476 × 0.9818 − 1 = 108/99 − 1：從 99 那天「就已經買進」。
Q2
print(round(p.iloc[-1] / p.iloc[0] - 1, 4))
0.08
買進持有的報酬。錯誤版本「打敗」了它，正確版本沒有。
Q3（找錯）
# AI 寫的「明天會漲就買」策略 up = (r.shift(-1) > 0).astype(int) s = up.shift(1) * r print(round((1 + s).prod() - 1, 4))
0.1333
每次都只抱上漲的日子：1.02 × 1.0606 × 1.0476 − 1。shift(-1) 用了明天的報酬當訊號——就算後面有 shift(1) 也沒用，訊號本身就偷看了未來。
Q4
print((sig != sig.shift(1)).sum())
2
第一天 0 和 NaN 比較算「不同」，第 4 天 0 → 1 也不同。要算真正的換手次數，請用下一頁的 diff()。
4. 交易成本：每換一次手，就付一次錢
chg = pos.diff() # 1 = 買進、-1 = 賣出 buy = (chg == 1) sell = (chg == -1) cost = buy * 0.001425 + sell * 0.004425 net = strat - cost n_trades = chg.abs().sum() # 換手次數
動作成本（單元 2 的規則）
買進手續費 0.1425%
賣出手續費 0.1425% ＋ 證交稅 0.3% = 0.4425%
一買一賣0.585%

（簡化：不計最低手續費 20 元、不計滑價）

💡 diff() = 今天 − 昨天。部位從 0 變 1 是買進（+1），從 1 變 0 是賣出（−1），沒變是 0。

一年來回進出 10 次，光成本就吃掉約 5.85%。短均線（5 日）的訊號很頻繁，常常是賺到的不夠付成本。

📌 回測報告一定要寫清楚：有沒有含成本？成本假設是多少？

6. 過度最佳化：「最好的參數」為什麼不可靠？

把台積電資料切成兩段：2024–2025 用來挑參數（樣本內），2026 用來驗證（樣本外）。都含交易成本。

  • 樣本內最好的是 60 日；但到了 2026，換成 120 日最好。
  • 試越多參數，越容易「剛好」找到一個在過去很漂亮的組合——這叫過度最佳化（overfitting）或資料探勘。
  • 5 日均線換手 129 次，成本吃光了獲利。
  • 再提醒一次：我們選台積電，是因為它事後漲最多；拿漲最多的股票測做多策略，本身就有選擇偏誤。

📌 正確做法：參數只用樣本內決定，報告樣本外的結果，並且和買進持有比較。

⚠️ 本單元的「AI 常犯錯誤」專欄

請 AI 寫回測時，這四件事幾乎一定要自己檢查：

① 忘了 shift（look-ahead bias）
用今天收盤才知道的訊號，賺今天的報酬。
👉 找出 sig * r，確認是 sig.shift(1) * r
② 沒有交易成本
換手越頻繁，差距越大。
👉 檢查有沒有 diff() 和成本假設
③ 只報告最好的參數
試了 20 組參數只秀最好的那組，等於拿答案對答案。
👉 要求分樣本內／樣本外
④ 沒有基準、只挑贏家
只說「賺了 95%」，卻沒說買進持有賺 336%；或只測事後漲最多的股票。
👉 一定要和買進持有比，並換其他股票試試
