1. Python 是什麼？

Python 是一種通用型程式語言，1991 年由荷蘭工程師 Guido van Rossum 發表。設計理念是「好讀、好寫」：程式看起來很接近英文。

price = 100 if price > 90: print("Expensive")

就算沒學過，大概也猜得出這三行在做什麼——這正是 Python 的特色。

「通用型」：什麼都能做

領域例子
資料分析整理、統計、畫圖（本課程重點）
人工智慧機器學習、ChatGPT 這類模型的開發
自動化自動下載資料、整理報表
網站、應用程式網站後端、小工具

💡 在財金業：量化交易、風險管理、資料分析、金融科技等職位，Python 已經是常見的要求條件之一。

2. 「開源」（Open Source）是什麼意思？
特性意思
免費任何人都可以下載、使用，不用買授權
原始碼公開程式怎麼寫的，大家都看得到、可以檢查
社群共同維護全世界的開發者一起改進、修正錯誤
套件豐富別人寫好的工具（套件）可以直接拿來用

📦 Python 的官方套件庫 PyPI 上有數十萬個套件。R 的套件庫 CRAN 也是同樣的概念——你在前 6 週已經用過了。

開源的優點與代價

✅ 優點：免費、更新快、新方法（例如 AI 工具）通常最先出現在 Python
⚠️ 代價：沒有官方客服，出問題要自己查、問社群或問 AI；不同版本的套件結果可能不一樣（單元 5 會遇到 pandas 新舊版本的差異）

💡 這也是本課程強調「看得懂、驗得了」的原因：工具是免費的，但判斷結果對不對，是你的責任。

3. Python 和其他分析工具有什麼不同？
工具費用操作方式常見使用領域特色
Excel付費（Office）點選、公式幾乎所有辦公室上手最快；資料一大、步驟一多就難以檢查與重做
SPSS商業授權（貴）選單點選為主社會科學、問卷分析統計檢定方便；彈性較低
SAS商業授權（貴）程式銀行、保險、藥廠大型機構傳統主力，穩定、有官方支援
MATLAB商業授權（貴）程式工程、數值計算矩陣運算強；資料處理與套件生態較小
R免費、開源程式統計、學術研究統計方法最齊全
Python免費、開源程式資料分析、AI、各行各業通用性最高，資料分析和 AI 的主流語言

💡 「寫程式」最大的好處是可重複：同樣的分析，換一份新資料、換一個月份，程式重跑一次就好；Excel 點選的步驟很難完整重做，也很難讓別人檢查。

沒有「最好」的工具，只有適合的情境。工作上可能會遇到任何一種；學會一種程式語言之後，再學其他的會快很多。

4. 從 R 到 Python：你已經會一半了
概念RPython
載入套件library(xxx)import xxx
指定變數x <- 10x = 10
一串資料c(10, 20, 30)[10, 20, 30]
表格data.framepandas.DataFrame
真／假TRUE / FALSETrue / False

自訂函式f <- function(x) {...}def f(x): ...
程式區塊用 { } 包起來用縮排表示

取範圍x[1:2] 含第 2 個x[0:2] 不含位置 2

兩種語言的概念幾乎一樣：變數、向量（list）、表格、函式、套件。差別主要在寫法。

最容易錯的三件事
① Python 的位置從 0 開始
② Python 用縮排決定程式範圍，空白不能亂加
③ True 只有第一個字母大寫

💡 寫 Python 時，R 的習慣會「偷跑」出來，這很正常。下一頁就來試試看。

🔍 預測輸出：小心 R 的習慣

各題使用 Python 的 x = [10, 20, 30]。想一想：同樣的寫法在 R 裡會得到什麼？

Q1
print(x[1])
20
Python 從 0 開始數，位置 1 是第二個。R 的 x[1] 是 10。
Q2
print(x[0:2])
[10, 20]
包含位置 0、不包含位置 2，只有 2 個元素。
Q3（R 和 Python 完全不同！）
print(x[-1])
30
Python 的 −1 是「最後一個」。R 的 x[-1] 卻是「去掉第一個」，得到 20 30。
Q4
print(len(x), x[2])
3 30
3 個元素，位置是 0、1、2；最後一個是 x[2]。R 寫成 length(x) 和 x[3]。
5. module、package、library：別人寫好的工具
名詞是什麼比喻
function 函式完成一件事的程式一把螺絲起子
module 模組一個 .py 檔，裡面有很多函式一個工具盒
package 套件很多 module 組成的資料夾一整個工具箱
library 函式庫泛稱，常和 package 混用工具間

💡 實務上不必嚴格區分 module 和 package，記得「要先 import 才能用」就好。

三種 import 寫法

import math # 整個載入 math.sqrt(16) # 4.0 from math import sqrt # 只拿其中一個 sqrt(25) # 5.0 import pandas as pd # 取綽號（慣例） pd.read_csv(...) # 之後都用 pd

安裝 vs. 載入

  • 安裝（只要一次）：把工具箱買回家。Colab 已經裝好 pandas、numpy、matplotlib。
  • 載入（每次都要）：import，把工具箱打開放到桌上。
  • 還沒裝的套件：用 pip install 安裝（見第 6 節）
🔍 預測輸出：import
Q1
import math print(math.sqrt(16))
4.0
開根號的結果是 float（有小數點）。
Q2
from math import sqrt print(sqrt(25))
5.0
用 from 載入，就不必再寫 math.。
Q3（會發生什麼事？）
print(sqrt(9)) from math import sqrt
NameError: name 'sqrt' is not defined
程式由上往下執行，還沒 import 就先用了。
Q4（會發生什麼事？）
import pandas as pd s = pandas.Series([1, 2])
NameError: name 'pandas' is not defined
取了綽號 pd，就要用 pd.Series。這是初學者最常見的錯誤之一。

種類例子要安裝嗎？
標準函式庫（跟 Python 一起來）math、random、datetime不用，直接 import
第三方套件（從 PyPI 下載）pandas、numpy、yfinance先 pip install 再 import

安裝名稱 ≠ import 名稱

pip installimport
pandaspandas（大多數一樣）
scikit-learnsklearn
beautifulsoup4bs4
⚠️ Colab 的提醒
Colab 的電腦是借來的：閒置太久或隔天重開，自己裝的套件就不見了，要重新執行 !pip install。pandas、numpy、matplotlib 是 Colab 預先裝好的，不受影響。
⚠️ AI 常犯錯誤
AI 常把 import 名稱當成安裝名稱，給你 pip install sklearn。正確的是 pip install scikit-learn。

看錯誤訊息分辨問題

錯誤訊息通常代表
ModuleNotFoundError套件沒安裝，或套件名打錯
NameError沒 import，或名字打錯（例如綽號用錯）
🔍 預測輸出：安裝與載入
Q5（會發生什麼事？）
import Pandas as pd
ModuleNotFoundError: No module named 'Pandas'
Python 分大小寫，找不到叫 Pandas 的套件。
Q6（會發生什麼事？）
!pip install scikit-learn import scikit-learn
SyntaxError: invalid syntax
安裝成功，但 import 名稱是 sklearn。- 會被當成減號，所以是語法錯誤。
Q7（會發生什麼事？）
import math print(math.sqrt(4))
2.0
math 是標準函式庫，不需要 pip install。
Q8（情境題）

昨天在 Colab 執行過 !pip install twstock，今天重新打開筆記本，直接從 import twstock 那一格開始執行。會發生什麼事？

ModuleNotFoundError: No module named 'twstock'
Colab 重新連線後，自己裝的套件不見了，要先重跑 !pip install 那一格。

9. AI 都會寫程式了，為什麼還要學 Python？

AI 會寫出「能跑、但算錯」的程式

財金資料特別容易出錯：價格被當成文字、百分比和小數搞混、日期沒對齊、用到「未來」的資料……程式不會報錯，只會給你一個看起來很合理的錯誤數字。

你要當的是「分析師」，AI 是你的助理

助理交上來的東西，你得看得懂、抓得出錯、說得出意義。

本課程重視比較不重視
✅ 讀懂程式在做什麼背語法
✅ 不執行就能預測結果從零寫出長程式
✅ 判斷結果合不合理程式寫得多漂亮
✅ 解釋數字的財金意義只會截圖交差

📝 考試為紙筆測驗、不開放 AI。題型以「讀程式、預測輸出、找錯誤」為主，和每個單元的課堂練習一致。
