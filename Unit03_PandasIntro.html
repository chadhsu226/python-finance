💡 本單元的核心觀念是 index（索引）：每一列的「名字」。用公司當 index 最直覺——「台積電那一列」。

1. Series：有「名字」的一串資料
import pandas as pd # 四位同學的帳戶餘額（萬元） names = ["Alice", "Bill", "Cathy", "David"] bal = pd.Series([100, 50, 30, 20], index=names) print(bal)
Alice 100 Bill 50 Cathy 30 David 20 dtype: int64

左邊一欄是 index（名字），右邊是 values（值）。

寫法意思結果
bal["Cathy"]用名字取值30
bal.iloc[0]用位置取值100
bal.index所有名字Alice、Bill、Cathy、David
bal.max()最大值100
bal.idxmax()最大值的名字Alice

💡 Series = list（單元 1）＋ 每個值都有名字。很像 dict：bal["Cathy"] 和 stock["price"] 的取法一樣。

⚠️ 如果沒有指定 index，pandas 會自動給 0, 1, 2, …，這時「名字」剛好等於「位置」，很容易混淆。

🔍 預測輸出 1：Series

各題使用：s = pd.Series([100, 50, 30, 20], index=["Alice", "Bill", "Cathy", "David"])

Q1
print(s["Cathy"], s.iloc[0])
30 100
一個用名字、一個用位置。
Q2
print(len(s), s.max(), s.idxmax())
4 100 Alice
idxmax() 回傳的是名字，不是 100。
Q3
print(s[["Alice", "David"]].sum())
120
用一個 list 一次取好幾個名字：100 + 20。
Q4
t = pd.Series([100, 50, 30]) print(t[1], t.index.tolist())
50 [0, 1, 2]
沒指定 index，自動給 0、1、2；t[1] 是名字為 1 的值。

3. loc（用名字）vs. iloc（用位置）
# loc：用 index 名字與欄名 df.loc["Bolt"] # 一列 df.loc["Bolt", "Close"] # 一格 df.loc[["Apex", "Crown"], ["Close", "EPS"]] df.loc["Bolt":"Delta", "Close"] # 含「Delta」 # iloc：用位置（從 0 起） df.iloc[0] # 第一列（Apex） df.iloc[-1, 0] # 最後一列、第一欄 df.iloc[1:3] # 位置 1、2（不含 3）
df.loc[["Apex", "Crown"], ["Close", "EPS"]] Close EPS Name Apex 100 5 Crown 30 2
lociloc
依據index 的名字、欄名第幾列、第幾欄（位置）
範圍含結尾不含結尾（和 list 切片一樣）
排序後還是找到同一家公司位置變了，可能換成別家

💡 要查「某一家公司」用 loc；要「排名第一的那家」才用 iloc（先排序再 iloc[0]）。

使用 mini_stocks 的 df（Apex～Fleet 的 Close：100, 50, 30, 20, 60, 40）

40 100

4. index 的威力：運算時「按名字配對」
price = pd.Series([100, 50, 30], index=["Apex", "Bolt", "Crown"]) # 注意：eps 的順序不同！ eps = pd.Series([2, 5, 10], index=["Crown", "Apex", "Bolt"]) pe = price / eps print(pe["Apex"], pe["Bolt"], pe["Crown"]) # 20.0 5.0 15.0

pandas 會先按名字配對：Apex 的股價除以Apex的 EPS（100 / 5），而不是「第一個除以第一個」。

# 只取 values（像 list）→ 按位置配對 print((price.values / eps.values).tolist()) # [50.0, 10.0, 3.0] ← 全錯！

名字對不上會怎樣？

bonus = pd.Series([1, 2], index=["Apex", "Delta"]) r = price + bonus print(r["Apex"], r.isna().sum()) # 101.0 3

只有Apex兩邊都有；Bolt、Crown、Delta 只出現在一邊，結果是 NaN（缺值）。

這就是 index 的意義：它是每一列的身分證。資料來源不同、順序不同時，pandas 靠 index 把同一家公司的資料配在一起。

🔍 預測輸出 4：按名字配對

p = pd.Series([40, 60], index=["Fleet", "Echo"])；e = pd.Series([-3, 4], index=["Echo", "Fleet"])

Q1
pe = p / e print(pe["Fleet"], pe["Echo"])
10.0 -20.0
Fleet：40 / 4；Echo：60 / (−3)。EPS 是負的（虧損），本益比就變負數——這樣的本益比沒有意義（單元 4 會處理）。
Q2
print((p.values / e.values).tolist())
[-13.333333333333334, 15.0]
40 / (−3)、60 / 4：按位置配對，公司配錯了。
Q3
d = pd.Series([1.0, 2.0], index=["Fleet", "Apex"]) print((p * d).isna().sum(), len(p * d))
2 3
名字聯集是 Echo、Fleet、Apex 3 個；只有Fleet兩邊都有，其餘 2 個是 NaN。
Q4

-20.0

📌 讀取中文資料：編碼（encoding）問題

從這裡開始用的是證交所的真實資料，公司名稱、產業別是中文。電腦存中文字有不同的「編碼」方式，最常見兩種：

編碼誰在用
UTF-8國際通用；Colab、pandas 的預設
Big5（cp950）證交所、政府網站下載的 CSV；繁中 Windows 的 Excel 預設

✅ 課程網站上的資料都已存成 UTF-8，用 pd.read_csv(DATA_URL + "檔名") 直接讀就好，不需要加 encoding。

以後自己下載資料時，卡住了先對照這張表

現象解法
出現 UnicodeDecodeError
（訊息裡有 codec can't decode）		檔案是 Big5，讀檔時加上

沒有報錯，但中文變成奇怪的符號編碼猜錯了，換另一種 encoding 試試

代碼被讀成整數 2330，index 裡沒有文字 "2330"。要寫 w.loc[2330] 才找得到——但 0050 這種代碼就會變成 50。
⚠️ 本單元的「AI 常犯錯誤」專欄

這些錯誤多半不會報錯，或報錯了 AI 就「換個寫法」繞過去：

① 股票代碼被讀成數字
loc["2330"] 找不到，AI 改成 loc[2330] 就「解決」了，但 0050 會變成 50。
👉 讀檔時加 dtype={"Ticker": str}
② 百分比單位
殖利率欄位 3.04 代表 3.04%，直接拿來乘金額會放大 100 倍。
👉 檢查：算出來的金額合理嗎？
③ 丟掉 index 改用位置配對
用 .values 或 list 運算，兩份資料順序不同就會配錯公司。
👉 盡量讓 pandas 用 index 配對
④ 用 iloc 找「某家公司」
排序或篩選之後，iloc[0] 就不是原來那家了。
👉 找特定公司用 loc
