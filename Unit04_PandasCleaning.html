1. 布林篩選：選出符合條件的股票

兩個步驟：先比較、再篩選

cond = df["DivYield"] > 4 # 每家公司一個 True/False high = df[cond] # 只留 True 的列 # 通常寫成一行 high = df[df["DivYield"] > 4]

多個條件：&（且）、|（或）

df[(df["Close"] > 30) & (df["EPS"] > 0)] df[(df["Industry"] == "Finance") | (df["DivYield"] > 5)] df[df["Industry"].isin(["Tech", "Shipping"])]

💡 df["DivYield"] > 4 得到的也是一個 Series：index 是公司名，值是 True/False。篩選就是「按 index 留下 True 的公司」。

和單元 1 不一樣！
• 要用 &、|，不能用 and、or
• 每個條件都要加括號
寫錯會出現 ValueError。

💡 True 當成 1、False 當成 0：(df["Industry"] == "Finance").sum() 就是 Finance 產業的家數。

3. groupby：分產業統計
df.groupby("Industry")["Close"].mean()
Industry Finance 25.0 Shipping 50.0 Tech 75.0 Name: Close, dtype: float64

一次算好幾個統計量

g = df.groupby("Industry")["DivYield"] g.agg(["count", "mean", "max"])
count mean max Industry Finance 2 4.5 5.0 Shipping 2 3.0 6.0 Tech 2 2.5 3.0

讀法：分組 → 選欄 → 計算

片段意思
df.groupby("Industry")依產業把公司分成幾組
["Close"]每組只看 Close
.mean()每組各算一次平均

結果的 index 變了！原本 index 是公司名，groupby 之後的 index 是產業名。所以要用 g["Finance"] 取值，而不是 g["Crown"]。

💡 df["Industry"].value_counts()：快速看每個產業有幾家。

5. 缺值 NaN：虧損公司「沒有」本益比
pe = df["PE"] # tw_valuation 的本益比 pe.isna().sum() # 2（台泥、中鋼） pe.count(), len(pe) # 29, 31 pe.mean() # 自動略過 NaN pe.dropna() # 刪掉 NaN pe.fillna(0) # 用 0 補 ← 危險！
df["PE"].fillna(0).sort_values().head(3) # 1101 0.00 ← 台泥（虧損） # 2002 0.00 ← 中鋼（虧損） # 2618 9.02 ← 長榮航

NaN 在這裡有意義：「不適用」

處理方式結果
fillna(0)❌ 虧損公司變成本益比 0 倍、全市場最便宜
保留 NaN⭕ 平均自動略過；NaN < 15 是 False，篩選時自動排除
dropna()⭕ 明確排除，但要說明排除了誰

AI 常常「為了讓程式能跑」寫 fillna(0)。程式不會報錯，但選股結果完全錯誤。補值前先問：這個缺值代表什麼？

⚠️ 本單元的「AI 常犯錯誤」專欄

選股與資料整理的錯誤，程式都能跑，只是選出錯的股票：

① 負本益比被當成便宜
PE < 15 會把虧損公司（負本益比）一起選進來。
👉 加上 PE > 0，或讓虧損公司的 PE 保持 NaN
② 用 0 補本益比缺值
fillna(0) 讓虧損公司變成「全市場最便宜」。
👉 先問：這個缺值代表什麼？
③ 平均數被極端值拉走
產業平均本益比被一兩家極端值主導（友達 160 倍）。
👉 同時看中位數、家數
④ 數字被當成文字
千分位逗號、「-」讓整欄變 object，sum 變成串接、排序變成字典順序。
👉 檢查：df.dtypes
