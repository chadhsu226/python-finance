課程資料 / DATA

課程資料都放在網站上，在 Colab 裡直接用網址讀取，不需要上傳檔案。

範例程式碼（以 2330.csv 為例）
import pandas as pd DATA_URL = "https://chadhsu226.github.io/python-finance/data/" df = pd.read_csv(DATA_URL + "2330.csv", parse_dates=["Date"])
  • DATA_URL 每次都一樣，只要定義一次。
  • 要讀其他檔案，把 "2330.csv" 換成下表中的檔名，例如 pd.read_csv(DATA_URL + "mini_stocks.csv")。
  • parse_dates=["Date"] 只用在有日期欄的時間序列資料；各檔案實際要加哪些參數，以各單元講義為準。
檔案內容單元
