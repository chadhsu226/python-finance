型態說明財金例子寫法

code = "2330" # 用雙引號 " " name = 'TSMC' # 單引號 ' ' 也可以，前後一致即可 price = 1050.5 # float lots = 2 # int：2 張 print(type(code), type(price), type(lots)) # <class 'str'> <class 'float'> <class 'int'>

💡 股票代碼為什麼用字串？代碼不拿來做加減，而且 "0050" 一旦被當成數字（例如用 Excel 開 CSV）就會變成 50。

int 和 float 混用會怎樣？

運算結果型態
2 + 1.53.5float
1000 * 22000int
1000 * 2.02000.0float
int(3.9)3int（直接捨去，不是四捨五入）

✅ 規則：只要有一個是 float，結果就是 float。數值上 2000 == 2000.0 是 True，所以混用計算通常沒問題。

⚠️ 要小心的是 int() 會捨去小數。例：10 萬元能買幾股？int(100000 / 1050.5) → 95（這裡捨去剛好是對的）。

運算符意義a=10, b=4

運算順序（和數學一樣）

** → * / // % → + -，有括號先算括號

3. 賦值 = 、比較 == 與邏輯運算

一個等號 vs. 兩個等號，意思完全不同！

寫法意思結果
x = 5賦值：把 5 存進 x沒有輸出
x == 5比較：x 等於 5 嗎？True / False
price = 100 # 賦值 price = price + 5 # 先算右邊（105），再存回左邊 print(price == 105) # 比較 → True

💡 price = price + 5 在數學上不成立，但在程式裡是「由右往左」：算出右邊，再放進左邊的變數。

比較運算（結果一定是 bool）

運算符意義x=10, y=5
== / !=等於 / 不等於False / True
> / <大於 / 小於True / False
>= / <=大於等於 / 小於等於True / False

邏輯運算：組合多個條件

運算符意義財金例子
and兩者都成立價格 > 均線 且 量 > 1000 張
or任一成立跌破停損 或 達到停利
not反轉 True / False不是交易日

4. 字串與 f-string 格式化

字串基本操作

code = "2330" ticker = code + ".TW" # 串接 → "2330.TW" print(len(code)) # 長度 → 4 print(int("50") + 20) # 字串轉整數 → 70

💡 在 Yahoo Finance 上，台股代碼要加 .TW，就是用字串串接做到的。

f-string：字串前加 f，在 { } 裡放變數

name = "TSMC" price = 1050.5 print(f"{name} close: {price}") # TSMC close: 1050.5

進一步：在變數後加「:格式」控制顯示方式

寫法（x = 1234567.891, r = 0.0567）輸出
f"{x:.2f}"1234567.89（小數 2 位）
f"{x:,.0f}"1,234,568（千分位、不留小數）
f"{r:.2%}"5.67%（自動 ×100 加 %）

5. List（串列）：存一串價格
prices = [100, 102, 99, 105, 110] # 索引: 0 1 2 3 4 # 負索引: -5 -4 -3 -2 -1 prices[0] # 100 第一天 prices[-1] # 110 最後一天 prices[1:3] # [102, 99] 不含索引 3 prices[-2:] # [105, 110] 最後兩天 len(prices) # 5 sum(prices), max(prices), min(prices) prices.append(108) # 加入新的一天

兩個一定要記住的規則

  1. 索引從 0 開始：第 1 天是 prices[0]。
  2. 切片 [a:b] 包含 a、不包含 b：prices[1:3] 只有 2 個元素。

💡 這兩個規則之後在 pandas（單元 3–4）會一直用到，例如 df.iloc[-5:] 就是取最後 5 筆。

🔍 預測輸出 5：List

以下各題都使用：prices = [100, 102, 99, 105, 110]

102 110
索引 1 是第 2 個元素；-1 是最後一個。
Q2

[102, 99]
包含索引 1、不包含索引 3。
Q3
print((prices[-1] - prices[0]) / prices[0])
0.1
(110 − 100) / 100 = 0.1，這就是「期間報酬率」。
Q4

加入一筆後長度變 6；最大值仍是 110。
6. Dictionary（字典）：用「名稱」查資料
stock = { "code": "2330", "name": "TSMC", "price": 1000 } stock["price"] # 1000 用 key 取值 stock["price"] = 1050 # 修改 stock["volume"] = 35000 # 新增一個 key "name" in stock # True 檢查 key 是否存在 len(stock) # 4
ListDictionary
取值方式位置（索引）名稱（key）
寫法[ ]{ key: value }
適合存一串同類資料（每日股價）一筆資料的多個欄位（代碼、名稱、價格）

💡 dict 的觀念就是 pandas DataFrame 的「欄位名稱」：df["Close"] 也是用名稱取資料。

🔍 預測輸出 6：Dictionary 與投資組合
stock = {"code": "2330", "name": "TSMC", "price": 1000} port = {"2330": 2, "0050": 5} # 持有張數 px = {"2330": 1000, "0050": 150} # 每股價格
Q1：一張的市值？
print(stock["price"] * 1000)
1000000
1 張 = 1000 股。
Q2
stock["price"] = 1050 print(len(stock), "volume" in stock)
3 False
修改已存在的 key 不會增加長度；沒有 "volume" 這個 key。
Q3
v = port["2330"] * px["2330"] \ + port["0050"] * px["0050"] print(v)
2750
2×1000 + 5×150 = 2750。
⚠️ 這裡的單位是「張 × 每股價格」，要再 ×1000 才是市值（275 萬）。單位錯誤是 AI 和人都常犯的錯！
⚠️ 本單元的「AI 常犯錯誤」專欄

以下錯誤程式都不會報錯，只會給你錯的數字。請養成檢查的習慣：

① 數字被存成文字
從網頁或 CSV 讀進來的價格可能是字串，"50" + "20" 會變成 "5020"。
👉 檢查：type(x)
② 百分比 vs. 小數
利率 5% 寫成 5 而不是 0.05，結果放大 100 倍。
👉 檢查：結果的大小合理嗎？
③ 單位沒換算
「張」和「股」、「千元」和「元」混用。
👉 檢查：每個變數的單位是什麼？
④ 索引差一格
以為 prices[1] 是第 1 天、以為 [1:3] 有 3 個元素。
👉 檢查：用小資料手算一次

🔁 每個單元都會有這個專欄，期末考會從這裡出題。

🧩 綜合練習：回到本單元的財金問題
stock = {"code": "2330", "name": "TSMC"} prices = [100, 102, 99, 105, 110] week_ret = (prices[-1] - prices[0]) / prices[0] avg = sum(prices) / len(prices) print(f"{stock['name']} ({stock['code']}.TW)") print(f"Weekly return: {week_ret:.1%}") print(f"Avg: {avg:.1f}, High: {max(prices)}, Low: {min(prices)}") print(prices[-2:], sum(prices[-2:]) / 2)

註：f-string 裡面取 dict 的值時，key 要改用單引號，避免和外面的雙引號衝突。

請寫出完整的 4 行輸出
TSMC (2330.TW) Weekly return: 10.0% Avg: 103.2, High: 110, Low: 99 [105, 110] 107.5
平均價 = 516 / 5 = 103.2；最後兩天平均 = (105+110)/2 = 107.5。
