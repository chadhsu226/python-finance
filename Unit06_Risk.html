1. 波動度：報酬率的標準差
# 課程資料放在網站上，不需上傳檔案 DATA_URL = "https://chadhsu226.github.io/python-finance/data/" w = pd.read_csv(DATA_URL + "adj_close_wide.csv", parse_dates=["Date"], index_col="Date").dropna() r = w.pct_change().dropna() # 日報酬 daily_vol = r.std() # 日波動度 annual_vol = r.std() * 252 ** 0.5 # 年化 annual_ret = r.mean() * 252 # 年化平均報酬

💡 一年約有 252 個交易日。252 ** 0.5 就是 √252 ≈ 15.87。

為什麼報酬乘 252，波動度卻乘 √252？

日 → 年原因
平均報酬× 252每天的報酬累加
變異數× 252每天獨立的變異累加
標準差× √252標準差 = √變異數

日波動 2% × 252 = 504%（荒謬）；× √252 ≈ 31.7%（合理）。

💡 一定要用報酬率算標準差，不是用股價。股價 2000 元的標準差當然比 50 元大，那不代表風險比較高。

🔍 預測輸出 1：波動度

各題使用：r = pd.Series([0.02, 0.0, -0.02])（平均剛好是 0）

Q1
print(round(r.std(), 4))
0.02
偏差平方和 = 0.0004 + 0 + 0.0004 = 0.0008；pandas 預設除以 n − 1 = 2 → 0.0004；開根號 = 0.02。
Q2
print(round(r.std() * 252 ** 0.5, 4))
0.3175
0.02 × 15.87 ≈ 31.75%：年化波動度。
Q3（找錯）
print(r.std() * 252)
5.04
年化波動度 504%？不合理——這是乘錯了，應該乘 √252。
Q4（版本陷阱）
import numpy as np print(round(np.std([0.02, 0.0, -0.02]), 4))
0.0163
numpy 預設除以 n（母體標準差），pandas 預設除以 n − 1（樣本標準差）。資料少時差很多；AI 混用兩者時，結果會對不起來。
2. rolling：移動視窗計算
c5 = pd.Series([100, 102, 99, 105, 110]) c5.rolling(3).mean() # [nan, nan, 100.33, 102.0, 104.67] # 第 3 天：(100 + 102 + 99) / 3 = 100.33 # 第 4 天：(102 + 99 + 105) / 3 = 102.0 # 第 5 天：(99 + 105 + 110) / 3 = 104.67

兩個最常用的財金應用

# 20 日均線 ma20 = c.rolling(20).mean() # 60 日滾動波動度（年化） rv60 = r.rolling(60).std() * 252 ** 0.5

rolling(n) 的意思是：每一天都往回看包含今天在內的 n 天，在這 n 天上做計算。

  • 前 n − 1 天資料不夠，結果是 NaN。
  • 可以接任何統計：.mean()、.std()、.max()、.min()。

💡 整段期間只算一個波動度，會看不出風險「什麼時候變大」。滾動波動度可以看到風險隨時間的變化——例如 2025 年 4 月的大跌。

🔍 預測輸出 2：rolling

各題使用：c5 = pd.Series([100, 102, 99, 105, 110])

Q1
print(c5.rolling(2).max().tolist())
[nan, 102.0, 102.0, 105.0, 110.0]
每次看「今天和昨天」兩天，取較大的。
Q2
print(c5.rolling(3).mean().count())
3
5 天中前 2 天是 NaN，只有 3 個有效值。
Q3
print(c5.rolling(5).mean().iloc[-1])
103.2
視窗 = 全部 5 天，就是單元 1 算過的平均價。
Q4
m = c5.rolling(3).mean() print((c5 > m).tolist())
[False, False, False, True, True]
NaN 比較都是 False；99 < 100.33；105 > 102；110 > 104.67。這就是單元 7 的「站上均線」訊號。
3. 最大回撤（Maximum Drawdown）：從高點最多跌多少？
p = pd.Series([100, 120, 90, 110, 80, 130]) peak = p.cummax() # 到目前為止的最高價 dd = p / peak - 1 # 離最高點跌了多少 mdd = dd.min() # 最大回撤
天012345

dd00−25%−8.3%−33.3%0

💡 cummax() 是「累積最大值」：每一天都記住「到今天為止看過最高的價格」。

最大回撤回答的是投資人最在意的問題：如果我不幸在最高點買進，帳面上最多會虧掉多少？

波動度看的是「平常的起伏」，最大回撤看的是「最痛的一次」。兩者要一起看。

⚠️ 回撤要用還原價（或累積報酬）計算，否則除息會被當成下跌。

🔍 預測輸出 3：最大回撤

各題使用：p = pd.Series([100, 120, 90, 110, 80, 130])

Q1
print(p.cummax().tolist())
[100, 120, 120, 120, 120, 130]
高點只會往上更新，不會往下。
Q2
dd = p / p.cummax() - 1 print(round(dd.min(), 4), dd.idxmin())
-0.3333 4
第 4 天（80）離高點 120 跌了 1/3。
Q3（陷阱）
print(p.min() / p.max() - 1)
-0.3846153846153846
最低價 80 ÷ 最高價 130：但 130 出現在 80 之後，不可能「先買在 130 再跌到 80」。這不是最大回撤。
Q4
print(dd.iloc[-1], (dd == 0).sum())
0.0 3
第 0、1、5 天都是「創新高」，回撤為 0。
4. 真實資料：4 檔股票的風險比較（2024/01～2026/09）
r = w.pct_change().dropna() summary = pd.DataFrame({ "ann_ret": r.mean() * 252, "ann_vol": r.std() * 252 ** 0.5, "mdd": (w / w.cummax() - 1).min()}) summary["ratio"] = (summary["ann_ret"] / summary["ann_vol"]) print(summary.round(2))

ratio = 每承擔 1 單位波動得到的報酬（類似夏普比率，這裡省略無風險利率）。

讀出財金意義

  1. 0050 波動最小、回撤最小，報酬/風險比反而最高——它本身就是 50 檔股票的組合。
  2. 2317 鴻海最大回撤 −50%：在高點買進，曾經腰斬。
  3. 2454 報酬最高、風險也最高：高報酬通常伴隨高風險。
  4. 3 檔的最大回撤都發生在 2025 年 4 月（4/7 多檔股票單日跌停 −10%）。

⚠️ 這段期間台股大多頭，年化報酬很高，不代表未來也會如此。

5. 把風險畫出來：回撤圖與滾動波動度
dd = w / w.cummax() - 1 dd[["2330", "0050"]].plot(title="Drawdown")

回撤圖越深、越久，持有的痛苦就越大。

6. 相關係數與分散投資
print(r.corr().round(2))
2330 2317 2454 0050 2330 1.00 0.58 0.53 0.92 2317 0.58 1.00 0.47 0.70 2454 0.53 0.47 1.00 0.66 0050 0.92 0.70 0.66 1.00
# 三檔等權重組合的每日報酬 port = r[["2330", "2317", "2454"]].mean(axis=1) print(port.std() * 252 ** 0.5)

mean(axis=1)：每一天把同一列的幾檔股票報酬取平均（axis=1 是「橫著算」）。

  • 相關係數介於 −1 和 1：越接近 1，越常一起漲、一起跌。
  • 2330 和 0050 高達 0.92：台積電占 0050 權重很高，買了 0050 再買台積電，分散效果有限。
  • 2317 和 2454 只有 0.47：放在一起，一檔跌時另一檔不一定跌。

💡 分散的關鍵：組合的波動度 ≤ 個股波動度的加權平均；相關係數越低，降得越多。這是投資學裡少數「免費的午餐」。

🔍 預測輸出 4：相關係數與分散

a = pd.Series([0.02, -0.02, 0.02, -0.02])；b = -a（每天都和 a 相反）

Q1
print(a.corr(b), a.corr(a * 2))
-1.0 1.0
完全相反 → −1；a × 2 只是放大，方向完全一致 → 1。
Q2
port = 0.5 * a + 0.5 * b print(port.std())
0.0
每天一漲一跌剛好抵銷，組合報酬永遠是 0，波動度 0——完全負相關的極端例子。
Q3（想一想）
port2 = 0.5 * a + 0.5 * (a * 2) print(round(port2.std() / a.std(), 2))
1.5
相關係數 = 1 時沒有分散效果：組合波動度 = 兩者波動度的平均（1 和 2 的平均 1.5 倍）。
Q4
x = pd.DataFrame({"A": [0.01, 0.03], "B": [0.03, 0.01]}) print(x.mean(axis=1).tolist(), x.mean().tolist())
[0.02, 0.02] [0.02, 0.02]
axis=1 是每一列（每天）平均；不寫 axis 是每一欄（每檔股票）平均。這裡剛好都一樣——換個數字試試看！
⚠️ 本單元的「AI 常犯錯誤」專欄
① 年化波動乘 252
應該乘 √252。檢查：年化波動度大於 100% 的個股非常少見。
👉 波動 × √252、報酬 × 252
② 用股價算標準差
高價股的「股價標準差」一定比較大，那不是風險。
👉 先算報酬，再算 std
③ 最大回撤用「最低 ÷ 最高」
沒考慮先後順序，最高點可能出現在最低點之後。
👉 用 cummax()
④ 報酬為 0 的假交易日
停牌、缺值補 0 的日子會讓波動度被低估。0050 在 2025/6/11～6/17 分割停牌，報酬連續 5 天是 0。
👉 先看資料，再算風險
