1. if / elif / else：讓程式做判斷
amount = 10000 # 成交金額 fee = amount * 0.001425 # 14.25 if fee < 20: fee = 20 # 最低 20 元 print(fee) # 20 ret = -0.03 if ret > 0: print("Up") elif ret == 0: print("Flat") else: print("Down")

三個語法重點

  1. 條件後面一定要有冒號 :
  2. 要執行的程式碼必須縮排（4 個空白）。縮排就是 Python 判斷「哪些程式屬於這個 if」的方式。
  3. 由上往下檢查，第一個成立的就執行，後面的全部跳過。

比較與邏輯（單元 1 學過）

== 等於（兩個等號！）、!= 不等於、and 兩者都成立、or 任一成立

🔍 預測輸出 1：if 條件判斷
Q1
amount = 30000 fee = amount * 0.001425 if fee < 20: fee = 20 print(fee)
42.75
30000 × 0.001425 = 42.75，已超過 20，所以 if 裡的程式不會執行。
Q2（注意順序）
score = 95 if score >= 60: grade = "Pass" elif score >= 90: grade = "Excellent" print(grade)
Pass
95 ≥ 60 已成立，後面的 elif 不會再檢查。範圍大的條件放前面，範圍小的條件就永遠輪不到。
Q3
price, ma, vol = 105, 100, 500 if price > ma and vol > 1000: print("Buy") else: print("Wait")
Wait
price > ma 成立，但 vol > 1000 不成立；and 要兩個都成立。
Q4
side, amount = "sell", 50000 tax = 0 if side == "sell": tax = amount * 0.003 print(tax)
150.0
賣出才收證交稅：50000 × 0.003 = 150.0（乘上 float，結果是 float）。
2. for 迴圈：重複做同一件事

寫法一：直接跑過 list 的每個元素

for p in [100, 102, 99]: print(p) # 100 # 102 # 99

寫法二：用 range() 產生數字

total = 0 # 先歸零 for i in range(1, 6): # 1,2,3,4,5 total = total + i # 即 total += i print(total) # 15（沒縮排）
寫法產生的數字
range(5)0, 1, 2, 3, 4
range(1, 5)1, 2, 3, 4
range(0, 10, 3)0, 3, 6, 9

和 list 切片一樣：range(a, b) 包含 a、不包含 b。range(1, 5) 只跑 4 次！

💡 縮排決定 print 在迴圈內還是外：在迴圈內會印很多次，在迴圈外只印最後結果一次。

🔍 預測輸出 2：迴圈跑幾次？
Q1
print(list(range(1, 5)))
[1, 2, 3, 4]
不包含 5。list() 只是把 range 的數字列出來給你看。
Q2
count = 0 for i in range(0, 10, 3): count += 1 print(count)
4
i 依序是 0、3、6、9，共 4 次（12 已超過 10）。
Q3
for i in range(3): print(i, end=" ")
0 1 2
range(3) 從 0 開始；end=" " 讓 print 不換行、改用空白隔開。
Q4
fv = 1000 for year in range(1, 4): fv = fv * 1.1 print(year, round(fv, 1))
3 1331.0
跑 3 次（year = 1, 2, 3）：1000 → 1100 → 1210 → 1331。迴圈結束後 year 停在最後一個值 3。
3. for 迴圈的財金應用

應用一：由每日報酬率算累積價值

value = 100 for r in [0.1, -0.1]: # 先漲 10%，再跌 10% value = value * (1 + r) print(round(value, 2)) # 99.0，不是 100！

📉 漲 10% 再跌 10%，不會回到原點。報酬率要用連乘，不能直接相加。

應用二：用索引比較「今天」和「昨天」

prices = [100, 102, 99, 105] rets = [] for i in range(1, len(prices)): # 從1開始 r = prices[i] / prices[i-1] - 1 rets.append(round(r, 4)) print(rets) # [0.02, -0.0294, 0.0606]

💡 4 個價格只能算出 3 個報酬率。從 i = 1 開始，是因為第一天沒有「昨天」可以比。

🔗 到了單元 5，pandas 的 pct_change() 一行就能做完應用二。但要看懂它的結果（例如為什麼第一筆是 NaN），就得先懂這個迴圈。

🔍 預測輸出 3：迴圈裡的財金計算
Q1
v = 100 for r in [0.5, -0.5]: v = v * (1 + r) print(v)
75.0
100 × 1.5 = 150；150 × 0.5 = 75。漲 50% 再跌 50%，虧了 25%！
Q2：數上漲天數
p = [100, 102, 99, 105, 105] up = 0 for i in range(1, len(p)): if p[i] > p[i-1]: up += 1 print(up)
2
比較 4 次：102>100 ✔、99>102 ✘、105>99 ✔、105>105 ✘（平盤不算漲）。
Q3
p = [100, 102, 99, 105] rets = [] for i in range(1,len(p)): rets.append(p[i]-p[i-1]) print(len(rets), sum(rets))
3 5
每日漲跌為 2、−3、6，共 3 筆，總和 5（剛好等於 105 − 100）。
4. while 與 break：不知道要跑幾次時

while：條件成立就一直跑

money = 100 years = 0 while money < 200: # 還沒翻倍就繼續 money = money * 1.08 # 年報酬 8% years += 1 print(years) # 10

💡 「72 法則」估計 72 / 8 = 9 年，實際上要到第 10 年才超過 200（第 9 年約 199.9）。

break：提早離開迴圈

for p in [100, 95, 88, 92]: if p < 90: print("Stop loss", p) break # 觸發停損就不再往下看

⚠️ while 一定要讓條件有機會變成 False，否則會變成無限迴圈（例如忘了更新 money）。

適合的情況
for知道要跑幾次（幾天、幾年、幾檔股票）
while跑到某個條件達成為止（翻倍、還清貸款）
🔍 預測輸出 4：while 與 break
Q1
for p in [100, 95, 88, 92]: if p < 90: print("Stop loss", p) break
Stop loss 88
遇到 88 就 break，後面的 92 不會再檢查。
Q2
n = 0 while n < 10: n += 4 print(n)
12
n：0 → 4 → 8 → 12。8 < 10 還會再跑一次，所以會「超過」10。
Q3（會發生什麼事？）
k = 0 while k < 3: print(k)
0 0 0 ……（無限迴圈）
k 永遠是 0，條件永遠成立。少了 k += 1。
5. def：自訂函式
def period_return(p0, p1): """Period return""" r = (p1 - p0) / p0 return r x = period_return(50, 55) print(x) # 0.1 print(period_return(100, 90)) # -0.1

預設參數：不給就用預設值

def fee(amount, rate=0.001425): return amount * rate fee(100000) # 142.5（用預設費率） fee(100000, 0.0005) # 50.0（電子下單折扣）
部分意義
def宣告「我要定義一個函式」
p0, p1參數：呼叫時傳進來的值
return把結果交回給呼叫的地方，並結束函式

return 和 print 不一樣！
print 只是顯示在螢幕上；return 才能把值存進變數、繼續計算。函式沒有 return，就會回傳 None。

💡 函式的好處：寫一次，換個價格、股數就能重複使用；AI 寫的程式也大量使用函式，看得懂才能檢查。

🔍 預測輸出 5：函式
Q1
def fee(amount, rate=0.001425): return amount * rate print(fee(100000), fee(100000, 0.001))
142.5 100.0
第一次用預設費率；第二次傳入的 0.001 取代了預設值。
Q2（print vs. return）
def double(x): print(x * 2) y = double(5) print(y)
10 None
函式內的 print 印出 10；但函式沒有 return，所以 y 是 None。
Q3
def check(r): if r > 0: return "Gain" return "Loss or flat" print(check(0))
Loss or flat
0 > 0 不成立，跳過第一個 return，執行到第二個 return。
Q4
def g(a, b=2): return a ** b print(g(3), g(2, 3))
9 8
g(3) = 3²；g(2, 3) = 2³。參數依照位置對應。
⚠️ 本單元的「AI 常犯錯誤」專欄

這些錯誤程式都能執行，只是答案不對：

① 迴圈多跑或少跑一次
range(1, n) 和 range(n) 搞混，複利少算一年、報酬率少一天。
👉 檢查：手數迴圈到底跑幾次
② 交易規則沒寫進去
忘了最低手續費 20 元、買進也收證交稅。
👉 檢查：用「很小的金額」和「賣出／買進」各測一次
③ 報酬率直接相加
+10% 和 −10% 加起來是 0，但實際是虧 1%。
👉 檢查：累積報酬要用 (1 + r) 連乘
④ 縮排錯一格
print 或 return 縮排在迴圈裡，結果只跑了一次就結束，或印出一大串。
👉 檢查：每一行屬於哪一層？

def trade_cost(price, shares, side="buy"): amount = price * shares fee = amount * 0.001425 if fee < 20: fee = 20 tax = 0 if side == "sell": tax = amount * 0.003 return round(fee + tax) print(trade_cost(10, 100)) print(trade_cost(50, 1000)) print(trade_cost(50, 1000, "sell")) total = 0 for s in ["buy", "sell"]: total += trade_cost(50, 1000, s) print(total)

20 71 221 292

② 50000 × 0.001425 = 71.25 → 71
③ 71.25 + 150（證交稅）= 221.25 → 221
④ 買 71 + 賣 221 = 292
